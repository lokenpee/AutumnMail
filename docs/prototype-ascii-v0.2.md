# 秋招邮件 Agent Web UI 原型 v0.2

> 形态：桌面 Web UI
> 顶部导航：首页、邮件、日历、设置
> 说明：本文是文字线框，用于确认信息架构和交互，不代表最终视觉样式。

## 0. 本次修订

根据最新反馈，v0.2 调整如下：

- 首页明确分成“统计”和“摘要”两个区域。
- 邮件页改成左右分栏：左边邮件列表，右边邮件详情。
- 邮件列表第一版不显示岗位名称，只显示公司。
- 面试、测评、笔试共用同一个完成勾。
- DDL 第一版显示到日，不显示具体时间。
- 日历不受顶部日期范围影响，使用独立的年月切换。
- 日历事件使用 `[测评 2] [笔试 1] [面试 1]` 形式的彩色胶囊。
- 点击公司名称进入“公司详情抽屉”，展示该公司全部邮件时间线。
- 邮件页顶部增加：`只看秋招`、公司标签、公司搜索框。
- 广告和垃圾邮件仍保留在邮件列表中，分类为“其他”，但默认可以被“只看秋招”过滤。
- 增加独立的“设置”入口。

## 1. 全局框架

```text
+--------------------------------------------------------------------------------------------------+
| 秋招邮件管家        [ 首页 ]   [ 邮件 ]   [ 日历 ]                  [已同步 09:30]   [ 设置 ]     |
+--------------------------------------------------------------------------------------------------+
```

约定：

- 首页和邮件页显示日期范围筛选。
- 日历页使用自己的月份切换，不受顶部日期范围影响。
- 设置入口先保持简单，后续可以放置：
  - 邮箱连接
  - 同步频率
  - 提醒策略
  - 标签颜色
  - 隐私与数据清理
  - 模型和 API 配置

### 2.2 交互

- 点击统计卡片，跳转到邮件页并自动应用筛选条件。
- 点击摘要中的事项，打开邮件详情。
- “今日到期”只显示未完成 DDL。
- “逾期任务”显示已经超过截止日且未完成的 DDL。
- “未来 3 天事项”同时包含 DDL 和面试事件。
- “新 Offer”显示最近新增的 Offer 邮件。

### 3.2 邮件列表

列表按接收时间从新到旧排序。

每封邮件在左侧列表显示：

- 邮件类别
- 公司名称
- 标题
- 正文前 20 字
- 公司标签
- 邮件类别标签
- DDL，若存在，只显示到日
- 右侧完成勾

第一版不显示岗位名称。

示例：

```text
[面试] 字节跳动                     [ ]
诚邀您参加字节跳动...
[字节跳动] [面试邀请] [DDL: 09-13]
```

### 3.3 完成勾规则

`[ ]` 和 `[x]` 的规则：

- 灰色 `[ ]`：未完成。
- 点亮 `[x]`：已完成。
- 点击立即切换，再次点击可以取消。
- 测评、笔试、面试共用同一个完成勾。
- Offer、拒绝、申请已收到、其他广告邮件不显示完成勾。
- 已完成邮件仍然保留在列表中，不自动删除。
- 已完成后自动取消对应的 DDL 或面试提醒。

### 3.4 邮件详情

右侧详情至少显示：

- 邮件类别
- 主题
- 公司
- 发件人
- 接收时间
- 邮件正文
- DDL，如果存在
- 完成状态
- 打开 163 原文
- 公司详情抽屉入口

邮件详情不是第四个页面，而是邮件页右侧的详情区域。选择左列表中的邮件后，右侧即时切换。

### 3.5 公司详情抽屉

点击公司名称或“公司详情”后，从右侧打开抽屉。

```text
+-----------------------------------------+
| 字节跳动                              X |
|-----------------------------------------|
| 当前状态: 面试中                        |
| 关联邮件: 4 封                          |
| 最近更新: 2026-09-11                    |
|-----------------------------------------|
| 2026-09-13  面试邀请               [邮件] |
| 2026-09-11  测评邀请               [邮件] |
| 2026-09-08  申请已收到             [邮件] |
| 2026-09-01  笔试邀请               [邮件] |
+-----------------------------------------+
```

抽屉内容：

- 公司名称
- 当前流程状态
- 全部相关邮件时间线
- 每封邮件的类别
- 每封邮件的时间和 DDL
- 点击邮件后切换左侧选中项和右侧详情
- 后续可以增加岗位维度，但第一版列表不显示岗位

### 3.6 顶部过滤按钮

邮件页顶部设置：

- `只看秋招`：过滤广告、垃圾邮件和其他无关邮件。
- `全部邮件`：显示所有邮件，包括其他。
- 公司快捷标签：例如 `[字节跳动]`、`[美团]`、`[腾讯]`。
- 公司搜索框：输入公司名称进行搜索。
- 日期范围：作用于邮件列表和首页统计，不影响日历。

广告和垃圾邮件：

- 仍然保留在邮件列表中。
- 公司标签显示为 `[其他]`。
- 邮件类别显示为 `[广告/无关]`。
- 不解析公司、岗位和 DDL。
- 默认“只看秋招”时不显示；切换到“全部邮件”后显示。

### 4.2 日期格规则

- 每一天显示三类彩色胶囊：
  - `[测评 N]`
  - `[笔试 N]`
  - `[面试 N]`
- 没有事件的类型不显示。
- 同一天有多条时显示数量。
- 点击某一天后，右侧显示当天完整列表。
- 点击“邮件”后打开邮件页，并选中对应邮件。
- 点击公司名称可以打开公司详情抽屉。
- 已完成的事件可以显示为空心胶囊或加对勾。
- 逾期事件可以使用红色边框或红色数字。
- 今天使用独立边框。
- 日历使用独立的月份切换，不受顶部日期范围影响。
- `[回到本月]` 自动回到当前月份。

## 5. 设置入口

设置入口保留，但先不扩展成复杂页面。

第一版可以包含：

- 163 邮箱连接
- 授权码更新
- 同步频率
- 提醒策略
- 标签颜色
- 是否将正文发送给模型
- 清除本地邮件索引

## 6. 当前仍需最终确认的细节

1. 邮件页右侧是否始终显示详情；建议默认显示最新或当前选中邮件。
2. 点击公司名称打开公司详情抽屉，还是直接切到公司详情页；当前采用抽屉。
3. 广告和垃圾邮件在“全部邮件”模式下是否置底，建议按时间正常排序。
4. 日历中的面试是否需要显示“已完成”状态，建议和邮件完成勾共用。
5. Offer 是否只做高亮，不提供完成勾，当前不提供。
6. 设置页是否需要在第一版就做完整，当前只保留入口。
