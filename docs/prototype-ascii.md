# 秋招邮件 Agent Web UI 原型 v0.1

> 形态：桌面 Web UI，顶部标题栏切换首页、邮件列表、日历。
> 说明：这是纯文字线框，用于确认信息架构和交互，不代表最终视觉样式。

## 1. 全局框架

三个页面共用顶部导航。

```text
+--------------------------------------------------------------------------------------------------+
|  秋招邮件管家       [ 首页 ]   [ 邮件列表 ]   [ 日历 ]       日期范围: [ 2026-09-01 - 2026-09-11 ] |
|                                                                          [同步状态: 09:30] [设置] |
+--------------------------------------------------------------------------------------------------+
```

约定：

- 当前页面使用高亮或下划线表示。
- 日期范围是全局筛选，三个页面共享同一份统计口径。
- 同步状态显示最近一次同步时间和是否正在同步。
- 设置中包含邮箱连接、提醒策略、分类颜色和隐私设置。

## 2. 页面一：首页

```text
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+

+----------------+----------------+----------------+----------------+----------------+----------------+
|   公司数       |   岗位数       |   测评数       |   面试数       |   Offer 数     |   拒绝数       |
|      24        |      38        |      12        |       5        |       2        |       9        |
+----------------+----------------+----------------+----------------+----------------+----------------+

+------------------------------------------------------+-------------------------------------------+
| 今日到期 (2)                                         | 未来 3 天事项 (5)                         |
|------------------------------------------------------|-------------------------------------------|
| [测评] 字节跳动 · 后端开发                           | [笔试] 美团 · 数据开发                    |

| 截止 09-11 20:00                         [打开邮件]  | 09-13 14:00                  [打开邮件]   |
+------------------------------------------------------+-------------------------------------------+
| 新 Offer (1)                                         | 逾期任务 (1)                              |
|------------------------------------------------------|-------------------------------------------|
| [Offer] 华为 · 算法工程师                            | [测评] 京东 · 数据分析                    |

```

### 2.2 布局建议

- 第一行是六个统计卡片，横排显示。
- 统计卡片支持点击，点击后带着筛选条件跳转到邮件列表。
- 下面采用 2 x 2 摘要卡片：
  - 今日到期
  - 未来 3 天事项
  - 新 Offer
  - 逾期任务
- 每个摘要项显示：邮件类别、公司、岗位、时间、打开邮件入口。
- 首页不展示完整正文，避免信息过载。

### 2.3 统计卡片交互

```text
点击 [测评数 12]
    -> 邮件列表
    -> 自动筛选：邮件类别 = 测评邀请
    -> 显示当前日期范围内的 12 封邮件
```

```text
+--------------------------------------------------------------------------------------------------+

+--------------------------------------------------------------------------------------------------+
| [拒绝] 某公司 · 产品经理                                            收到: 09-09              [ ] |

+--------------------------------------------------------------------------------------------------+
```

右侧小方框约定：

- `[ ]`：灰色勾，未完成。
- `[x]`：点亮，表示已完成。
- 点击立即变更，再次点击可以取消。
- 只有测评、笔试和面试显示可点击状态。
- Offer、拒绝、申请已收到和其他邮件不显示完成勾选。
- 类型不属于这三类时，右侧可以保留空位，避免列表高度变化。

### 3.2 列表行内容

每封邮件建议展示三层：

1. 邮件类别、公司、岗位、关键时间、完成勾。
2. 标题和正文前 20 个字。
3. 公司、类别、DDL 或状态标签。

示意：

```text
[邮件类别] 公司 · 岗位                                  DDL/时间                     [ ]

标题：邮件主题
摘要：正文前 20 个中文字符
标签：[公司名称] [邮件类别] [时间状态]
```

其中：

- 日期或时间必须是用户能快速判断行动优先级的信息。
- 公司标签使用中性色。
- 邮件类别使用对应颜色。
- DDL 使用日期和紧急状态。
- 其他广告或垃圾邮件统一显示 `[其他] [广告/无关]`，不解析公司、岗位和流程。
- 默认排序：`received_at DESC`，最新的在最上方。
- 支持加载更多或无限滚动。

### 3.3 筛选栏

建议保留以下筛选：

- 公司
- 岗位
- 邮件类别
- 是否有 DDL
- 是否已完成
- 是否逾期
- 日期范围
- 关键词搜索

图中的缩写：

如果 UI 空间足够，可以把缩写替换成更直观的小胶囊：

```text
+----------------------+
| 18                   |
| [测评 2] [笔试 1]    |
| [面试 1]             |
+----------------------+
```

### 4.2 日期点击详情

点击某一天后，右侧显示当天的完整列表：

```text
9 月 18 日

[面试] 字节跳动 · 后端开发
14:00
[打开邮件]

[测评] 美团 · 数据开发
截止 23:59
[打开邮件]

[笔试] 腾讯 · 客户端开发
截止 20:00
[打开邮件]
```

点击公司或“打开邮件”后，进入对应邮件详情页。

### 4.3 日历交互

- `[ < ]` 和 `[ > ]` 切换上一个月或下一个月。
- `[回到本月]` 自动回到当前月份。
- 点击日期后右侧展示当天的 DDL 和面试。
- 已完成项可以用空心标记或对勾表示。
- 逾期项使用红边或红色数字。
- 今天使用独立边框。
- 日期格中同时显示测评、笔试和面试，使用不同颜色区分。
- 日期范围筛选是否影响日历视图需要在原型确认时决定：建议日历不受顶部日期范围限制，但显示筛选提示。

## 5. 原型中需要确认的问题

1. 首页统计卡片是 6 个横排，还是分成“统计”和“摘要”两个区域？
2. 邮件列表是否要显示“岗位名称”，还是第一版只显示公司？
3. DDL 显示到日还是显示到分钟？
4. 面试完成后点亮勾，是否和测评、笔试使用完全相同的交互？
5. 其他广告/垃圾邮件是否仍显示在邮件列表，还是默认折叠？
6. 日期范围筛选是否影响日历，还是日历独立按月份浏览？
7. 日历日期格使用 `A/W/I` 缩写，还是使用彩色图标和数字？
8. 点击公司名称时，是进入公司详情页，还是直接进入对应邮件？
9. 是否需要邮件详情页作为第四个页面？
10. 顶部导航是否需要单独的“设置”入口？
